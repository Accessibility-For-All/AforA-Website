- **Infra fix (not a PR — a repo Settings change via `gh api`):** GitHub Pages' source was set

  to serve that branch — so **every PR preview link this repo has ever posted has 404'd**, since
  before this session. Fixed via `gh api -X PUT .../pages -f source[branch]=gh-pages`, then a
  forced rebuild. Confirmed working: PR #19's preview now actually loads. See
  [[github-pages-source-branch]].
