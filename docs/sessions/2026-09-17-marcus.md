## Gotchas found (memory updated)
- **GTM strips custom attributes off external `<script src>` tags in Custom HTML** — any
  attribute-configured snippet (like GHL's) must createElement + setAttribute inline.
- **robots.txt Disallow paths must be extensionless on Cloudflare Pages** — `.html` rules
  never match the canonical URLs.
- Turnstile renders into closed shadow DOM — "is there an iframe" is the wrong render check;
  look for the container's hidden input instead.
- SEO-agent knowledge cutoffs can contradict current law — its "deadline dates are wrong"
  finding was itself outdated (April 2026 IFR extended them). Primary source (ADA.gov) wins.
