## Gotchas found (all in memory/ too)
- **Cloudflare Pages publishes the entire repo root** — deploy.yml/preview.yml excludes don't
  apply. Fixed via build command. See memory/cloudflare-pages-publishes-everything.md.
- **Pages serves static files BEFORE `_redirects`** — a rule can never shadow an existing file
  (forced deleting the two redirect-stub pages).
- **Pages 308s `/foo.html` → `/foo` natively** — any alias named like a real page's basename
  creates an infinite loop. Targets in `_redirects` must be extensionless.
- **Pages picks up env-var changes only on the NEXT deployment** (and "Retry" of an old
  deployment did NOT pick them up; the next git push did).
- **A `www` CNAME alone ≠ redirect** — proxied CNAME with no origin binding = 522. The
  "Redirect from WWW to root" Rules template is the fix.
- GHL session can expire mid-automation (billing page navigation logged it out once).
- **No GoHighLevel MCP connector exists** in the registry (checked 2026-08-05) — GHL automation
  is browser-only via Marcus's logged-in Chrome.
